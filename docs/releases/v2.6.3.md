English: Stability release. Fixes a crash when a chat was saved or redrawn while the agent was still writing (ConcurrentModificationException), a chat deadlock when a new message was sent while an approval/clarify prompt was open, and that prompt lingering after Stop/New chat. Transient network drops are now retried. Shared files are no longer attached twice after the activity is recreated; Activity leaks fixed. The local 127.0.0.1 bridge authenticates before reading the body, caps request size, times out idle clients and can no longer crash the app. Telegram allow-lists no longer match a user's first name (anyone could set it). UI: status/navigation bar icons follow the skin's light/dark mode, no double keyboard gap in Terminal, long titles ellipsize, user bubbles size to their text, low-contrast secondary text in 8 skins raised to WCAG AA, and the chat no longer yanks you to the bottom while you read earlier messages. CI publishes releases only from version tags.
Note: Telegram allow-list entries must now be a numeric user id or @username (a first name no longer grants access).
Install over the previous version to preserve data. Android ARM64 only.
OpenCode Free upstream access restrictions remain; listing a model does not prove inference access. No physical-device login/native performance certification is claimed. Remote integrations require user configuration and their own host.
