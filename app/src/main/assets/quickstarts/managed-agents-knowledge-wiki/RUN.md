# Run steps (Hermes sandbox adaptation)

Runtime: Python in the Alpine sandbox. Needs YOUR OWN Anthropic API
key: put ANTHROPIC_API_KEY in Hermes Settings → Environment (never
paste keys into chat).

1. Create the project from this template in the IDE panel.
2. In the sandbox terminal inside the project folder:
   `pip install -r requirements.txt` (or `pip install anthropic`
   if the starter has no requirements file).
3. Run the starter's Python entry point from its README.
4. If a step needs a desktop display, Docker, or VNC, it is out of
   scope on the phone — the README states which steps those are.

Original: https://github.com/anthropics/claude-quickstarts
