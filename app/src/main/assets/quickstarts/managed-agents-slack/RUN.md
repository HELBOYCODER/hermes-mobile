# Run steps (Hermes sandbox adaptation)

Runtime: Node.js in the Alpine sandbox. Needs YOUR OWN Anthropic API
key: put ANTHROPIC_API_KEY in Hermes Settings → Environment (never
paste keys into chat).

1. Create the project from this template in the IDE panel.
2. In the sandbox terminal inside the project folder:
   `npm install` then `npm run dev` (or the start script named in
   the README).
3. Open the local URL the dev server prints, in Hermes' Browser
   screen or the phone browser.
4. If a step needs Docker, a desktop app, or a third-party account
   beyond your Anthropic key, it is out of scope on the phone — the
   README states which steps those are.

Original: https://github.com/anthropics/claude-quickstarts
