# Run steps (Hermes sandbox adaptation)

Runtime: see this starter's README (mixed layout) — follow its
install steps inside the Alpine sandbox terminal in the project
folder. Needs YOUR OWN Anthropic API key: put ANTHROPIC_API_KEY in
Hermes Settings → Environment (never paste keys into chat).
If a step needs Docker, a desktop display, or VNC, it is out of
scope on the phone.

Original: https://github.com/anthropics/claude-quickstarts
