# ECC skill catalog (Hermes index — Hermes-written, not ECC text)

Source: https://github.com/affaan-m/ECC (MIT).
Count honesty note: the post cites 311 skills and 71 specialist agents.
This snapshot's canonical skill set is 47 skills under
`.agents/skills/` (the repo mirrors the same skills across client
directories — .cursor, .kiro, .claude, etc. — which is where larger
counts come from; 1,068 SKILL.md files exist repo-wide including
those mirrors). This index lists the 47 canonical skills. Specialist
agent definitions live in the repo under `.kiro/agents/` and similar
client agent dirs; Hermes' six team roles (planner, researcher,
implementer, tester, reviewer, security auditor) are Hermes' own
wording adapted from that specialist-agent concept, not copied agent
files.

## How to use (on-demand fetch, APK stays small)

Full skill texts are NOT bundled. When a skill below matches a task,
fetch it user-initiated via Skills → Import Anthropic skill with
`ecc:<name>` (e.g. `ecc:deep-research`) or the raw URL shown per
skill. The fetched SKILL.md then lists like any bundled skill.
Limitation: only SKILL.md is fetched; a skill's references/ and
scripts/ are not — if the skill needs them, it says so when loaded.

## Behaviour triggers (a used skill must change behaviour)

- A security-related skill (e.g. security review) triggers a security
  pass in the Team-mode reviewer/security stage — it is not just listed.
- A testing skill triggers real test runs in the tester stage.
- A research skill triggers research-first behaviour: check docs/code
  before writing (the researcher stage).
- A documentation skill triggers doc updates alongside code changes.
If a fetched skill cannot change behaviour on the phone (needs a
desktop tool), the agent says so instead of pretending.
