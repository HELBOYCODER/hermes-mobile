# Fullstack Engineering
1. Inspect service boundaries, data contracts, dependencies and existing tests.
2. Specify API inputs, outputs, auth and error behavior before changes.
3. Use parameterized database queries, migrations, least-privilege credentials, and safe secret storage.
4. Add input validation, rate limits, structured errors, observability and tests.
5. Check backwards compatibility, performance and rollback before shipping.
6. Never treat local-only or simulated integrations as deployed production features.
