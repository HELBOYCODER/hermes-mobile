# Vibe Coding
1. Clarify the user goal and acceptance criteria; inspect existing repository first.
2. Make a short implementation plan with affected files, interfaces, and tests.
3. Implement the smallest working vertical slice. Reuse existing components and patterns.
4. Run relevant build, lint, and tests. Fix failures; never claim success without logs.
5. Show actual changed files, limitations, and next steps. Obtain approval before destructive actions.
6. Never expose tokens, credentials, or private data.
