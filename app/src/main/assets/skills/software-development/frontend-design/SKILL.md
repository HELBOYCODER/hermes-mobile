# Frontend Design
1. Inspect the app framework and design system; use existing tokens and components.
2. Define typography, spacing, color, responsive states, and interaction hierarchy.
3. Build semantic accessible UI with keyboard focus, labels, RTL support, and reduced motion.
4. Use motion only where it improves comprehension; avoid unnecessary heavy dependencies.
5. Validate with screenshots or browser tests when a browser tool is configured; otherwise state that visual validation is unavailable.
6. Do not copy proprietary designs or assets without permission.
